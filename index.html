02 About

Precision over flourish.

I'm a full-stack developer based in Baku. I build production web platforms for banks, transport authorities and private companies — from database schema to deployed interface.

Most of my work runs on Laravel and PHP or ASP.NET and C#, backed by MySQL and SQL Server. I care about the parts users don't see: data integrity, access control, performance under load, and code the next developer can read.

Recent work includes the IPO subscription platform for PASHA Capital, the public site for Baku International Bus Terminal, and Satiram marketplace.
